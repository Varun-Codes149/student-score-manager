# Student Score Manager

A simple and professional web-based Student Score Management System.

## Features

- Calculate total marks
- Calculate average
- Calculate percentage
- Automatic grade calculation
- PASS / FAIL result
- Find highest and lowest subject
- Add student records
- Search students
- Load student records
- Delete student records
- Class topper
- Class average
- Export records to CSV
- Saves records in the browser using local storage
- Works offline

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Open `index.html` in a web browser.
2. Enter the student's details.
3. Enter marks for all subjects.
4. Click **Calculate**.
5. Click **Save Student** to save the record.
